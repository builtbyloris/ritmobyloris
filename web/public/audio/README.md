# RITMO Focus audio

Le tracce `rain-thunder.mp3`, `ambient-drift.mp3` e `forest.mp3` sono state generate appositamente per RITMO tramite il DSP procedurale versionato in `scripts/generate-focus-audio.mjs`.

- Non contengono campioni, registrazioni o materiale di terze parti.
- Sono asset originali del progetto RITMO byloris.
- Sorgente: PCM stereo a 44,1 kHz e 16 bit.
- Distribuzione web: MP3 stereo a 160 kbit/s.
- Durata: 3 minuti per traccia.
- La riproduzione applica fade-in, fade-out e crossfade prima del riavvio della traccia.

`ambient-drift.mp3` usa esclusivamente sintesi armonica originale: pad stereo lentamente modulati, accordi sospesi e interventi cristallini radi, senza campioni o rumore naturale simulato.

I riferimenti Freesound valutati in fase di design non sono inclusi perché il download dei file originali richiedeva autenticazione.
